Legal

Sedogin Inc. is committed to user privacy. Sedvai processes all voice commands locally on your device — no recordings are uploaded to our servers. System permissions (microphone, screen) are used solely to execute your commands. Anonymous crash diagnostics may be collected to improve performance. If you connect external AI providers via API key, their own privacy policies apply. Your API keys are stored locally and encrypted.

By using any Sedogin Inc. product, you agree to use it lawfully and not attempt to reverse-engineer, decompile, or extract source code without explicit permission. All software is provided "as is" — Sedogin Inc. is not liable for data loss or hardware issues arising from use. We reserve the right to update our products and these terms at any time.
